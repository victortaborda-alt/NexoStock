# Inventario Frontend

Cliente React + TypeScript + Vite para `NexoStock.Api`.

## Ejecutar

Desde esta carpeta:

```powershell
npm install
npm run dev
```

La aplicación queda en `http://localhost:5173` y usa el proxy de Vite para enviar `/api` a `http://localhost:5027`.

## Acceso de prueba

- Usuario: `admin@inventario.test`
- Contraseña: `Admin123!Test`

El usuario de prueba se configura en User Secrets del backend; las credenciales no forman parte del repositorio.
